# Документация по проектной (учебной) практике

## Общая информация

В рамках проектной практики разработаны два продукта: веб-платформа **«ГеоРеклама»** (агрегатор объектов наружной рекламы) и игра **«Арканоид»** (шарик, бита, надвигающиеся кирпичи).

---

## Цель практики

Получение навыков разработки и оформления программных проектов, включая работу с Git, создание веб-сайта и игрового приложения, оформление документации.

---

## Ход выполнения практики

### 1. Подготовка среды
- Создан репозиторий, освоены базовые команды Git.

### 2. Анализ предметной области
- Изучен рынок наружной рекламы, конкуренты, целевая аудитория.
- Сформулированы требования к MVP платформы.

### 3. Разработка платформы «ГеоРеклама»
- Создан многостраничный сайт с левым боковым меню.
- Реализованы разделы: Главная, О нас, Услуги, Портфолио, Блог, Контакты.
- Выполнена адаптивная вёрстка.

### 4. Разработка игры «Арканоид»
- Создана игра на Canvas с механикой надвигающихся кирпичей.
- Реализованы: бита (управление мышью/тачем), шарик (изменение угла отскока), кирпичи (разрушаемые, добавляются сверху).
- Система очков, жизней (3), усложнение с каждой волной.

### 5. Документирование
- Подготовлена документация в формате Markdown.

### 6. Взаимодействие с партнёром
- Участие в мероприятии ПАО «Ростелеком»: локации, призы, научный фильм, нетворкинг, подача заявления на работу.

---

## Используемые технологии

| Технология | Назначение |
|------------|------------|
| Git | Контроль версий |
| HTML/CSS | Структура и стили |
| JavaScript | Логика игры и сайта |
| Markdown | Документация |

---

## Результаты

- Веб-платформа «ГеоРеклама»
- Игра «Арканоид»
- Документация в Markdown
- Организованный репозиторий

---

## Вывод

Практика позволила закрепить навыки веб-разработки, создания интерактивных Canvas-приложений, работы с Git и документирования проектов. Разработанные продукты могут использоваться как основа для дальнейшего развития.# Документация по проектной (учебной) практике
