# Документация: Сравнительный анализ игр «Арканоид» (на чистом JS и на Phaser)

## 1. Введение

В рамках проектной практики была разработана игра **«Арканоид — шарик, бита и кирпичи»** на чистом JavaScript с использованием Canvas. Для сравнения был изучен классический туториал с MDN Web Docs — **«2D breakout game using Phaser»** (разработка игры «Арканоид» с использованием игрового фреймворка Phaser).

В данном документе представлен анализ ключевых **изменений и отличий**, которые были внесены в игру из репозитория (`brickgame.html`) по сравнению с реализацией, описанной в туториале.

## 3. Ключевые изменения (детальное описание)

### 3.1. Отказ от фреймворка в пользу чистого JS

**В туториале (Phaser):**
- Используется сторонняя библиотека Phaser.
- Требуется подключение скрипта Phaser.
- Синтаксис специфичен для фреймворка (сцены, спрайты, физический движок).

**В прикреплённом файле:**
- Чистый JavaScript без зависимостей.
- Отрисовка через Canvas API.
- Физика и коллизии реализованы вручную.

```javascript
// Пример: ручная проверка коллизий вместо встроенного физического движка Phaser
if(ballRight > left && ballLeft < right && ballBottom > top && ballTop < bottom) {
    // обработка столкновения
}
```

---

### 3.2. Уникальная механика: надвигающиеся кирпичи

**В туториале:**
- Кирпичи статичны, находятся в фиксированных рядах.
- После разрушения всех кирпичей игра заканчивается победой.

**В прикреплённом файле:**
- Кирпичи постоянно движутся вниз (`bricksSpeedY`).
- При опускании верхнего ряда ниже порога — добавляется **новый ряд сверху**.
- Реализована **бесконечная игра** с волнами и усложнением.

```javascript
// Движение кирпичей вниз
for(let b of bricks) {
    if(b.status === 1) b.y += bricksSpeedY;
}

// Добавление нового ряда сверху
if(minActiveY > 35 && bricks.length > 0) {
    let newRowY = minActiveY - BRICK_H - 3;
    // создаём новые кирпичи
}
```

---

### 3.3. Управление мышью и сенсором (вместо клавиатуры)

**В туториале:**
- Управление с помощью клавиш **влево/вправо**.

**В прикреплённом файле:**
- Управление **мышью** (движение курсора по Canvas).
- Поддержка **сенсорных экранов** (`touchmove`).
- Курсор скрыт на игровом поле (`cursor: none`).

```javascript
// Мышь
canvas.addEventListener('mousemove', handleMouseMove);
// Сенсор
canvas.addEventListener('touchmove', handleTouchMove);
```

---

### 3.4. Дополнительные условия потери жизни

**В туториале:**
- Жизнь теряется только при падении мяча за нижнюю границу.

**В прикреплённом файле:**
- Жизнь теряется также, если **кирпичи касаются биты**.

```javascript
if(b.status === 1 && (b.y + b.h) >= paddleY - 2) {
    loseLife("Кирпичи достигли низа!");
}
```

---

### 3.5. Система усложнения (волны)

**В туториале:**
- Уровень сложности не меняется.

**В прикреплённом файле:**
- После уничтожения всех кирпичей начинается **новая волна**:
  - Увеличивается количество рядов (`rowsToGenerate + 1`).
  - Увеличивается скорость движения кирпичей (`bricksSpeedY += 0.12`).
  - Начисляется бонус `+200` очков.

```javascript
if(!anyAlive && bricks.length > 0) {
    rowsToGenerate = Math.min(rowsToGenerate + 1, 9);
    bricksSpeedY += 0.12;
    score += 200;
}
```

---

### 3.6. Визуальный стиль

**В туториале:**
- Простые цвета и формы (без теней и градиентов).

**В прикреплённом файле:**
- **Градиентный фон** с сеткой.
- **Многослойная отрисовка** кирпичей (4 слоя заливки для объёма).
- **Тени** у биты и шарика.
- **Блики** на шарике.

```javascript
// Пример: объёмный кирпич
ctx.fillStyle = "#ff69b4";
ctx.fillRect(b.x, b.y, b.w-1, b.h-1);
ctx.fillStyle = "#ff99cc";
ctx.fillRect(b.x+2, b.y+2, b.w-5, b.h-5);
```

### 3.7. Информационная панель и статус

**В туториале:**
- Только счёт и (иногда) жизни.

**В прикреплённом файле:**
- Отдельная панель со **счетом, жизнями и кнопкой перезапуска**.
- **Динамическая статусная строка** с сообщениями:
  - `🎮 двигай мышью → зеленая бита`
  - `⚠️ потеряна жизнь! осталось X ⚠️`
  - `✨ ВОЛНА КИРПИЧЕЙ! УСЛОЖНЕНИЕ ✨`
  - `💀 ИГРА ОКОНЧЕНА`

---

### 3.8. Адаптация под мобильные устройства

**В туториале:**
- Отсутствует (предполагается только десктоп).

**В прикреплённом файле:**
- Мета-тег `viewport` с `user-scalable=no`.
- Медиа-запросы для экранов до 780px.
- Поддержка `touchmove` с `preventDefault()`.

## 5. Выводы

Игра, разработанная в рамках проектной практики (`brickgame.html`), представляет собой **существенно расширенную и модифицированную версию** классического «Арканоида» по сравнению с базовым туториалом MDN.

**Основные направления доработки:**
1. **Отказ от фреймворка** в пользу чистого JS — полный контроль над логикой.
2. **Уникальная игровая механика** — надвигающиеся кирпичи и бесконечные волны.
3. **Улучшенный UX** — управление мышью/тачем, статусная строка, мобильная адаптация.
4. **Визуальное оформление** — тени, градиенты, объёмные объекты.

Таким образом, финальный продукт является **самостоятельной реализацией**, которая сохранила базовую идею классического «Арканоида», но добавила ряд оригинальных функций, повышающих реиграбельность и техническую сложность проекта.
